# 考研每日工作台

西南财经大学 · 金融专硕（431）考研冲刺每日工作台。目标 400+，76 天倒计时（2026-12-19 考试）。

一个可安装到安卓手机的网页 App（PWA）：倒计时 + 高中课表式固定时间块 + 每天 4 条定量"作业" + 76 天分阶段计划。勾选进度保存在手机本地，可导出备份。

## 目录

- `index.html` / `style.css` / `app.js` — 应用本体
- `plan.js` — 76 天逐日任务数据（改计划改这里）
- `manifest.json` / `sw.js` / `icons/` — PWA 安装与离线支持
- `plan.md` — 76 天文字版计划

## 一、在电脑上本地打开（无需部署）

直接双击 `index.html`，用浏览器（Chrome/Edge）打开即可使用。勾选进度会存在本机浏览器里。

## 二、部署到 GitHub Pages（可装到手机）

1. 注册一个 GitHub 账号（免费）。
2. 新建一个**公开**仓库，名字填 `kaoyan-dashboard`。
3. 把本目录所有文件上传到该仓库（可以用网页「upload files」上传，或安装 Git 后命令行推送）。
4. 仓库 → Settings → Pages → Source 选 `main` 分支、根目录 `/` → Save。
5. 等一两分钟，得到网址：`https://你的用户名.github.io/kaoyan-dashboard/`。

## 三、安装到安卓手机

1. 手机 Chrome 打开上面的网址。
2. 点右上角菜单（⋮）→「**安装应用**」或「**添加到主屏幕**」。
3. 桌面出现「考研工作台」图标，点开就是全屏 App，**断网也能用**。

## 四、数据备份（重要）

勾选进度只存在手机浏览器本地，换手机 / 清浏览器数据会丢。建议：

- 每周：设置页 →「导出备份」→ 存一个 `.json` 文件（发到自己微信「文件传输助手」）。
- 恢复：设置页 →「从文件导入」或「从粘贴内容导入」。

## 五、怎么改计划

- 改每天任务：编辑 `plan.js` 里的 `MATH_TASKS` / `ENGLISH_TASKS` / `POLITICS_TASKS` / `MAJOR_TASKS` 数组（76 条，对应 10/4 → 12/18）。
- 改考试日期：App 设置页里直接改，或改 `plan.js` 顶部的 `EXAM_DATE`。
- 改课表：编辑 `plan.js` 里的 `SCHEDULE`。

改完重新部署（或本地刷新）即可。
